# Cüzdanım (PWA yedeği, sürüm 14)

Bu dal, React Native'e geçmeden önceki çalışan web uygulamasının (PWA) yedeğidir.

- `index.html`: yayına hazır, tek dosyalık uygulama (HTML, CSS, JavaScript)
- `kaynak/app.html`: düzenlenebilir kaynak, `kaynak/build.py` ile `index.html` üretilir
- `sw.js`, `manifest.webmanifest`, simgeler: PWA dosyaları

Yayındaki adres `main` dalından sunulur: https://sefauzunoglu.github.io/cuzdanim/
